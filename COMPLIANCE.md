# Compliance checklist

Blocking gates from master prompt §3. Not legal advice; items marked "lawyer" need a qualified one.

| Item                                      | Requirement                                                                                                                                    | Status                                                                                                              |
| ----------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Age gate                                  | Birth month and year asked at sign-up; minimum 14 in Spain, 16 elsewhere; only the band is stored                                              | Done and tested (API and web)                                                                                       |
| Web3 for adults only                      | Wallet, NFTs, marketplace and claims hidden below 18                                                                                           | Rule implemented in `@nyrgo/shared` (`canUseWeb3`) and tested; enforced on web3 routes in Phase 3                   |
| GDPR lawful basis                         | Location processed only for active gameplay; privacy policy                                                                                    | Policy text pending (lawyer review before launch)                                                                   |
| GDPR access and portability (art. 15, 20) | Download of all personal data as JSON                                                                                                          | Done and tested (`GET /v1/me/data-export`)                                                                          |
| GDPR erasure (art. 17)                    | Account deletion; personal data removed, ledger rows anonymized                                                                                | Done and tested (`DELETE /v1/me`)                                                                                   |
| GDPR rectification (art. 16)              | Edit display name; email change                                                                                                                | Display name done; email change not yet                                                                             |
| Retention                                 | Precise location 24 h, samples 30 days; expired sessions and links purged                                                                      | **Samples now stored on every nearby query; purge job due in milestone 4 (blocks public testing)**                  |
| Processors                                | DPA with hosting, email and any tile provider                                                                                                  | Pending provider choice                                                                                             |
| OSM license                               | ODbL attribution on the map and in API responses; derived POI database offered under ODbL if published                                         | Attribution done (map control, POI layer, `/v1/world/nearby`); share-alike applies only if we publish the POI table |

| Safety of locations                       | No objectives at schools, hospitals, police, military, playgrounds, water, major roads, rail or private homes; driving warning above 30 km/h   | Exclusion zones done and tested; driving warning done; interactions disabled at speed in milestone 4                |
| Loot boxes                                | No paid randomized items                                                                                                                       | Enforced by design; nothing paid exists yet                                                                         |
| Trademark                                 | Search for the commercial name before public branding ("nyrgo" is a codename), and for the 50 creature names (some include slang such as HODL) | Not started; banned-word test blocks known brands, coins and owned memes                                            |
| App stores                                | Review NFT and crypto rules before any native release                                                                                          | Not applicable yet                                                                                                  |
